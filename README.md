# Aryamaan Dash Portfolio

A Next.js portfolio site for Aryamaan Dash, designed for deployment on Vercel.

## Prerequisites

- Node.js `>=22.13.0`

## Quick Start

```bash
npm install
npm run dev
npm run build
```

## Useful Commands

- `npm run dev`: start local development
- `npm run build`: verify the production Next.js build
- `npm test`: build and run a small rendered-content check
- `npm run lint`: run ESLint

## Deployment

Import the repository into Vercel. Vercel will detect Next.js and run
`npm run build`.
